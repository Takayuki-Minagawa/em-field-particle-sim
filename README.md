# 電場・磁場と荷電粒子の運動シミュレーター

電場・磁場中を運動する荷電粒子の軌跡を、ブラウザ上で 3D 表示しながら学べる教育用 Web アプリケーションです。  
高校物理の電磁気分野を主な対象とし、ローレンツ力、等速円運動、らせん運動、電場と磁場の組み合わせによるドリフトや速度選別器の考え方を、視覚的に確認できる構成にしています。

このリポジトリは静的フロントエンドのみで構成されており、GitHub Pages での公開を前提としています。

## 公開リポジトリとしての前提

- 本アプリは教育目的の教材です。研究用、実験制御用、設計用の厳密な数値計算ソフトウェアではありません。
- 画面上の値は理解しやすさを優先した正規化表現であり、実験室スケールの実測値を直接再現するものではありません。
- アプリケーション専用のサーバー、認証機能、ユーザー情報保存機能は含みません。
- リポジトリ内に個人情報、秘密鍵、認証情報を含めない前提で管理してください。
- 本アプリは外部バックエンドを必要としませんが、表示フォントの取得で外部配信資産を参照する場合があります。

## できること

- 一様電場 `E = (Ex, Ey, Ez)` の各成分を調整
- 一様磁場 `B = (Bx, By, Bz)` の各成分を調整
- 電場のみ、磁場のみ、平行場、垂直場、速度選別器のプリセット切替
- 粒子の質量、電荷、初期位置、初速度の調整
- 複数粒子を同時に配置して軌道を比較
- 3D ビューで粒子、軌跡、速度ベクトル、力ベクトル、場の矢印を表示
- 再生、一時停止、リセット、再生速度変更、軌跡長の変更
- 速度、運動エネルギー、サイクロトロン半径、位置量の時系列表示
- 状態に応じた説明文の生成
- 6 ステップの学習レッスン（予想 → 実験 → 観察の流れで、電場の力・ローレンツ力・円運動・らせん運動・速度選別器・E × B ドリフトを学習）
- ゲーム感覚のミッション 6 種（クリア条件の自動判定、達成度メーター、ヒント、クリア演出）
- レッスン・ミッションの進捗をブラウザ内（localStorage）に保存
- 3D ビュー上の凡例、経過時間表示、再生ツールバー、ミッション目標（的・ゲート）の表示
- キーボードショートカット（Space: 再生 / 一時停止、R: リセット）
- クイズ形式での確認問題（正解数の表示付き）
- 日本語 / 英語切替
- ライト / ダークテーマ切替
- PC、タブレット、スマートフォン向けのレスポンシブ表示

## 画面構成

本アプリは、以下の 3 層構成を基本としています。

### 1. 操作パネル

- 場のプリセット選択
- 電場・磁場ベクトルの調整
- 粒子の追加、削除、選択
- 質量、電荷、初期位置、初速度の調整
- 再生制御、軌跡長、カメラ追尾、視点リセット

### 2. 3D シミュレーションビュー

- 電場、磁場の矢印グリッド表示
- 粒子の現在位置表示
- 軌跡ラインの表示
- 速度ベクトル、ローレンツ力ベクトルの表示
- 任意視点からの回転、ズーム、追尾
- 条件に応じたサイクロトロン半径のガイド表示

### 3. 学習パネル / 数値パネル

学習パネルは 4 つのタブで構成します。

- レッスン: ステップごとの要点・公式・予想問題。予想を選ぶと実験が自動で再生され、観察ポイントと発展課題が表示されます
- ミッション: 学んだ内容を使って条件をクリアする課題。進行中は 3D ビューにも達成度が表示されます
- 解説: 現在状態に応じた説明文
- クイズ: 力の向き、半径、速度選別器に関するクイズ

数値パネルでは、速度、エネルギー、半径、位置量の簡易グラフを表示します。

## プログラム仕様

### 計算モデル

荷電粒子の運動は、以下のローレンツ力に基づいて更新します。

`m dv/dt = q(E + v × B)`

- `m`: 質量
- `q`: 電荷
- `E`: 電場ベクトル
- `B`: 磁場ベクトル
- `v`: 粒子速度

### 数値積分

- 数値積分には `Boris 法` を採用しています。
- 磁場中の回転運動を比較的安定して表現できるため、教育用のリアルタイム表示に適しています。
- 内部では粒子速度に応じて時間刻みを調整し、極端な発散を抑えるようにしています。

### 物理量表示

アプリ内では、以下の値を補助的に表示します。

- 速度
- 運動エネルギー
- ローレンツ力の大きさ
- 加速度の大きさ
- サイクロトロン半径
- サイクロトロン周期

サイクロトロン半径と周期は、磁場または電荷が 0 に近い場合には定義しません。

### 可視化仕様

- 電場ベクトルは青系
- 磁場ベクトルは暖色系
- 速度ベクトルは緑
- 力ベクトルは赤
- ミッションの目標（的・ゲート）は明るい緑
- 円運動のガイドリングは、E × B ドリフト系で見た回転の中心（案内中心）に表示
- 粒子軌跡は粒子ごとに色分け
- 軌跡は時間経過に応じた色の変化を持つラインとして表示

## 学習コンテンツ仕様

学習パネルでは、現在の場と粒子状態から以下を生成します。

- どの場が支配的か
- 力が主に速度の向きを変えているのか、速さを変えているのか
- 円運動、らせん運動、ドリフトの見え方
- `E × B` ドリフトの考え方

### レッスン

`src/data/lessons.ts` で定義しています。各レッスンは要点・公式・予想問題・観察ポイント・発展課題と、実験用の場と粒子の初期条件を持ちます。

1. 電場から受ける力 `F = qE`
2. 磁場から受ける力 `F = qv × B`（フレミングの左手の法則）
3. 等速円運動 `r = mv / (qB)`、`T = 2πm / (qB)`
4. らせん運動
5. 速度選別器 `v = E / B`
6. `E × B` ドリフト

### ミッション

`src/lib/missions.ts` で定義しています。各ミッションは初期条件と判定関数を持ち、シミュレーション状態から達成度とクリアを判定します。

| ミッション | 内容 |
| --- | --- |
| 電場ロケット | 静止した陽子を電場で加速し、x = 4 までに速さ 4 以上にする |
| 放物線シュート | 下向き電場の中で陽子を的に当てる |
| ぴったり半径 2 | 磁場中で半径 2 の円運動をさせる |
| らせんを描け | 磁場方向の速度成分を加えてらせん運動をさせる |
| まっすぐゲートを通せ | 速度選別器の条件 v = E / B で直進させる |
| 流れを逆転させよ | E × B ドリフトの向きを反転させる |

### クイズ

クイズは以下の 3 系統を実装しています。

- ローレンツ力の向き
- サイクロトロン半径の見積もり
- 速度選別器の通過条件 `v = E / B`

## GitHub Pages 公開

GitHub Pages 用の Actions ワークフローを同梱しています。

- 定義ファイル: `.github/workflows/deploy.yml`
- 対象ブランチ: `main`
- 主な処理:
  - 依存関係インストール
  - テスト実行
  - ビルド実行
  - `dist/` を GitHub Pages へデプロイ

`vite.config.ts` では、GitHub Actions 実行時にリポジトリ名をもとに `base` を設定するため、リポジトリ配下の Pages 公開にも対応します。

## テスト方針

現在は主に軽量なロジックテストを実装しています。

- ベクトル演算の基本挙動
- 磁場のみの場合のエネルギー保存傾向
- 電場中での加速挙動
- 学習パネル用の説明文とクイズ生成
- 各ミッションが初期条件ではクリアできず、想定した操作でクリアできること
- レッスンの予想問題の整合性と、速度選別器レッスンで v = E / B の粒子だけが直進すること

UI の視覚確認や操作性確認は、必要に応じてブラウザ上で追加確認してください。

## 制約と注意

- 教材用途のため、物理定数や実単位系を厳密に再現する設計ではありません。
- 多数粒子や高密度描画を前提とした最適化は行っていません。
- 3D 描画ライブラリの都合により、ビルド時に比較的大きな JavaScript チャンクが生成されることがあります。
- ブラウザ性能や端末性能によって描画の滑らかさは変わります。
